# V0 completion boundary

V0 ends when Meridian's independent synthetic sources, known defects, documentation, tests, simulator and reusable architecture viewer work together locally.

## Intentionally deferred to V1

V1 will solve a new problem: moving operational records into durable analytical storage without destroying the original representation. That is when ingestion, S3 landing/bronze zones, Parquet where suitable, metadata manifests, quarantine, Glue, Athena, Terraform, IAM and KMS become relevant.

None of those capabilities belongs in V0.

V0 source contracts and raw sample artifacts must remain compatible inputs to V1. V1 should add around V0 rather than rewriting the simulated bank.
